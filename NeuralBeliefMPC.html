Neural Belief Corrections for MPC: Plan-Consistent Scalar Budgets versus Myopic Directional Constraints

Thanana Nuchkrua, Xiaoqi Liu, and Sudchai Boonto
Technical Note submitted to IEEE Transactions on Automatic Control, 2026

Reference belief \(\mathfrak{B}^r_t\) → Neural proposal \((m,P)\) → Budgets \(\delta_E,\ \varepsilon_B\) → MPC cell \(\mathcal{C}\) → Input tolerances \(\bar u_c,\ \bar u_a\)

The controller's input tolerances fix how far a neural observer may move its belief. A single scalar budget keeps the whole predicted input plan within tolerance; constraining only the applied input admits corrections that later inputs amplify — and in closed loop, plan consistency is still not safety.

Neural Belief MPC asks a simple question about online-adapted neural observers: how far may the observer move its belief before the controller's input changes by more than a prescribed tolerance? We answer it with two certified belief budgets set directly from the input tolerances, and then show what happens when the simple scalar budget is replaced by sharper, controller-direction constraints.

CF observer at one decision tick: the reference and the replay cache inform accept/hold; the projected belief feeds the controller.

What Is the Problem?

An online-adapted neural observer changes the belief from which a certainty-equivalent MPC computes its input in two distinct ways at every tick: the encoder corrects a reference belief, and accepted parameter updates move the belief computed from the same context. Prediction-score descent bounds neither change, whereas a control designer thinks in tolerances on input changes. The question is which belief budgets guarantee prescribed input tolerances — and how conservative the simplest such budget is.

Two Budgets and a Design Rule

  • Every-correction budget (Theorem 1): each deployed correction obeys \(W_2(b_g,b_r)\le\delta_E\) with respect to its reference, including ticks without adaptation.
  • Same-context update budget (Theorem 2): every accepted parameter update moves the belief computed from the same context by at most \(\varepsilon_B\) — a limit the correction budget alone cannot enforce.
  • Controller-to-observer rule (Corollary 1): inside a known affine MPC cell \(\mathcal{C}\) with gain \(g_M=\|K_MS_x\|_2\), \[ \delta_E\le\min\{\delta_{\mathcal C}(\widehat x_r),\ \bar u_c/g_M\},\qquad \varepsilon_B\le\bar u_a/g_M \] keeps the current QP feasible and bounds correction- and adaptation-induced input changes by \(\bar u_c\) and \(\bar u_a\), without a true-state error bound.

Scalar Budget versus Directional Constraints

The scalar rule is a ball; the controller only "sees" the directions in the row space of its input map. Constraining those directions directly over the first \(H\) predicted inputs gives a larger set \(\mathcal{D}_B\supseteq\mathcal{S}_B\).

  • Theorem 3 (Scalar-envelope conservatism): \(\mathcal S_B\subseteq\mathcal D_B\), with a nested-projection inequality; the extra corrections admitted by \(\mathcal D_B\) lie, up to an explicit margin, in \(\ker G_H\).
  • Proposition 3 (Plan consistency and myopia): the scalar ball keeps all \(N\) predicted correction-induced inputs within \(\bar u_c\); with \(H=1\), later predicted inputs can be driven up to \(\gamma_k\sqrt{\tau^{\star2}-r_s^2}\), and under nominal propagation the next applied inputs and states are amplified by explicit factors.

Core Insight

Admitting more belief motion in directions the current input does not see is not free: later inputs see it. Constraining the whole horizon restores plan consistency, but plan consistency is not safety — for this observer the scalar rule's conservatism is protective, and admitting more belief motion requires independent evidence that the proposal is accurate.

Simulation Study: Single and Double Inverted Pendulum

Do sharper, controller-aware belief constraints help a neural observer in closed loop with MPC?

The plants are the official DeepMind Control Suite cart–pole and its two-pole generator, simulated in MuJoCo with RK4 at a 20 ms control tick. Positions and angles are measured with noise, velocities are hidden, and five profiles (nominal, last-pole mass +50%, angle bias, angle dropout, combined) are run with five seeds per plant. Scope

The certificates hold in exact arithmetic under the stated covariance, domain and cell assumptions; they bound belief and input changes, not true-state estimation error. The trials establish neither an adaptation or covariance benefit nor nonlinear safety or recursive feasibility.

Reproducibility

All simulations, observers and MPC run in Julia 1.12.1 with pinned environments; post hoc projection studies and certificates use Python (NumPy, CVXPY/Clarabel, SciPy). The 50 replays reproduce the archived test logs bit for bit.
